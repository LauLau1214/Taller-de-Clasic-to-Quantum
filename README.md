 - **`classical_system.py`**  
  Ejemplo de modelado de un sistema discreto determinista usando matrices y vectores.  
  Muestra el cálculo del estado del sistema después de uno y dos pasos (clicks).

- **`probabilistic_double_slit.py`**  
  Simulación de la versión probabilística del experimento de la doble rendija.  
  Representa probabilidades de detección usando una matriz de transición estocástica y muestra un diagrama de barras con las intensidades en cada detector.

- **`quantum_double_slit.py`**  
  Simulación de la versión cuántica de la doble rendija.  
  Utiliza amplitudes complejas y calcula las probabilidades como el cuadrado del módulo de las amplitudes resultantes.  
  Incluye visualización de las probabilidades en cada detector.

- **`wave_interference_double_slit.py`**  
  Simulación de la doble rendija usando un modelo de ondas.  
  Calcula la interferencia mediante superposición de ondas y muestra el patrón de interferencia en la pantalla (máximos y mínimos de intensidad).
